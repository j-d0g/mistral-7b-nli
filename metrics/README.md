# Metrics and Visualizations

This directory contains the figures used in the documentation and the JSON data behind them. Every data figure is generated by a script in `scripts/analysis/` from the public data and result files; the diagrams are drawn by `generate_card_visualizations.py`.

## Diagrams

`data_pipeline.png`, `dataset_banner.png`, `model_architecture.png`, `reasoning_benefits.png`, `reflection_process.png` (all from `generate_card_visualizations.py`).

## Metrics data

- `card_metrics.json`: split sizes, label balance, estimated token statistics and test-set metrics. Its `_comment` fields name the commands that reproduce each block.
- `original_token_vs_accuracy.json`: agreement with the gold label by estimated rationale length for the `open-mistral-7b` rationales (train and dev)
- `finetuned_token_vs_accuracy.json`: accuracy by estimated rationale length for the fine-tuned model on the test set

## Regenerating

From the project root, after `python3 data/download_data.py` and `python3 results/download_results.py`:

```bash
python scripts/analysis/compute_test_metrics.py          # prints the test-set metrics
python scripts/analysis/analyze_token_lengths.py --train-file data/finetune/train_ft.jsonl --dev-file data/finetune/dev_ft.jsonl --test-file data/original_data/test.csv
python scripts/analysis/analyze_original_thoughts.py
python scripts/analysis/analyze_finetuned_results.py
python scripts/analysis/plot_training_dynamics.py
python scripts/analysis/generate_card_visualizations.py
```

Token counts are estimated as characters / 4, not with the Mistral tokenizer. `analyze_token_lengths.py` writes a fresh `card_metrics.json` without the `models` block; copy the test-set metrics from `compute_test_metrics.py` back in before running `generate_card_visualizations.py`, or keep the committed `card_metrics.json`.

See `scripts/analysis/README.md` for details of each script.
